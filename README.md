# Olympic Detailing

Лендинг детейлинг-студии Olympic Detailing (Минск).

## Стек

- TanStack Start / React
- Vite + Nitro (деплой на Vercel)

## Локальный запуск

```bash
npm install
npm run dev
```

Скопируйте `.env.example` в `.env` и заполните `VITE_SITE_URL`, Telegram-токены при необходимости.

## Сборка

```bash
npm run build
```
