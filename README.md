# AMG Detailer Studio

Create a high-end, visual-heavy, premium car detailing landing page for a studio named "AMG".

### Design & Aesthetic

- Style: Masculine, juicy, modern, dynamic, luxury, high-contrast, strictly high-end automotive feel.

- Color Palette: Deep rich black background (#0B0B0B), bold crimson red accents (#E50914 or vibrant neon red), clean crisp white text for max contrast.

- Branding: Studio logo placeholder "AMG" in the navigation bar and footer.

### Core Business Info

- Address: Краснодар, улица Мачуги, 157

- Phone: +7 (918) 965-95-95

- Working hours: Ежедневно с 9:30 до 19:00

### Page Structure & Content Requirements

1. Header / Navbar:

   - "AMG" logo placeholder on the left.

   - Smooth-scroll navigation links: Услуги, Галерея, FAQ, Контакты.

   - Top Bar / Header Info: Working hours ("9:30 - 19:00") and Phone (+7 (918) 965-95-95).

   - Call-to-action button: "Записаться".

2. Hero Section:

   - Dynamic entrance animation: High-resolution dark aesthetic image of a modern Mercedes-AMG entering or glowing on page load.

   - Bold Headline: "Премиальный детейлинг авто в Краснодаре".

   - Subtitle: "Защита кузова, оклейка пленками и профессиональная шумоизоляция для вашего автомобиля".

   - Primary CTA Button: "Получить консультацию" (Opens a pop-up modal form on click).

3. Core Services Grid (Услуги):

   - Modern grid cards with hover-zoom effect and subtle red glowing borders.

   - Use smart placeholder text for detailing descriptions:

     * Card 1 (Main): Оклейка плёнкой (Защитные антигравийные и виниловые плёнки)

     * Card 2 (Main): Шумоизоляция (Комплексная шумоизоляция салона, арок и багажника)

     * Card 3 (Placeholder): Детейлинг полировка и керамика

     * Card 4 (Placeholder): Химчистка и уход за салоном

   - Each card should have a "Заказать" button that opens the appointment modal.

4. Interactive FAQ Section (Вопросы и ответы):

   - Smooth animated accordion with collapsible panels containing placeholder answers for common detailing queries (warranty, application time, film durability).

5. Instagram Media Grid (Наш Instagram):

   - Section Title: "Наш Instagram"

   - Grid layout featuring high-quality automotive image and video thumbnail placeholders.

   - Hover effect: Image zooms slightly with an Instagram icon overlay.

   - Clicking an item opens Instagram in a new browser tab.

6. Lead Capture Modal (Pop-up Form):

   - Clicking any "Записаться" or "Получить консультацию" button opens a sleek dark-themed pop-up modal.

   - Input fields: Ваше имя (Name), Телефон (Phone Number), Марка авто (Car Model), Выберите услугу (Service Select Dropdown).

   - Submit button: "Отправить заявку".

   - Form Behavior: On submit, show a smooth "Спасибо! Мы перезвоним вам" success notification message (no real backend/data routing needed for now).

7. Footer & Contact Section:

   - Integrated dark map placeholder showing "Краснодар, ул. Мачуги, 157".

   - Full contact details (+7 (918) 965-95-95, 9:30 - 19:00).

   - Quick action buttons: "Позвонить" and "Написать в WhatsApp".

### Animations & UX

- Smooth scroll animations (fade-in, slide-up) as the user scrolls.

- Mobile-first, fully responsive design optimized for smartphones.
